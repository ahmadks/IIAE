## 📌 Overview

The **IIAE (Intelligent Invariant Audit Engine)** is a professional technical standard designed to audit the **coherence, preservation, and epistemic validity** of responses generated by artificial intelligence systems. 

The IIAE serves as a deterministic verification layer that ensures an AI agent remains within its defined "Epistemic Admissible Manifold" by analyzing whether it:
*   **Preserves Canonical Axioms**: Maintains the system's core invariants.
*   **Detects Semantic Drift**: Measures noise or unintended deviations.
*   **Identifies Hallucinations**: Flags content not supported by the authorized knowledge base.
*   **Evaluates Logical Consistency**: Detects explicit contradictions using Entailment models.

---

## ⚙️ Technical Architecture

The engine orchestrates a multi-dimensional auditing pipeline:

1.  **Semantic Embeddings**: High-precision vector alignment for axiom preservation.
2.  **Mini-RAG (Deterministic)**: A local retrieval-augmented generation layer for clause-level verification.
3.  **Logical Entailment (MNLI)**: Cross-encoder logic gates to detect formal contradictions.
4.  **DQE (Dissonance Quantification Engine)**: The core mathematical engine that computes the deterministic deviation (Epsilon).
5.  **Epistemic State Machine**: Final classification into standard system states: `REGISTERED`, `SUPPORTED`, `SPECULATIVE`, or `QUARANTINED`.

## 🚀 Quick Start

### 1. Installation
```bash
git clone https://github.com/yourusername/IIAE.git
cd IIAE
pip install -r requirements.txt
```

### 2. Model Pre-caching (Optional but Recommended)
The app will automatically download models on first run (~175MB), but you can pre-cache them:
```bash
python download_models.py
```

### 3. Run the Audit Dashboard
```bash
streamlit run streamlit_app.py
```

## ⚖️ Epistemic Status Definitions

| Status | Description |
| :--- | :--- |
| **REGISTERED** | Perfect or near-perfect alignment with canonical axioms. |
| **SUPPORTED** | High validity with minor admissible semantic drift. |
| **SPECULATIVE** | Content contains noise or weakly supported claims. |
| **QUARANTINED** | Critical failure: Explicit contradiction or severe hallucination detected. |
